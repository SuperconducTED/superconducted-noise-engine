HOW THE ENGINES WORK

Engine 1: Type-1 Fuzzy

1 · Features

Mean T1, T2, readout error over all qubits

(shared stage 1)

2a · Membership functions (MFs)

3 per input, shared by all rules: 9 MFs

Gaussian (2 parameters) or Triangular, TanhBell (3 parameters)

2b · 27 rules

3 × 3 × 3 grid

Firing strength f_r: product of the rule's 3 MF degrees

Output, first-order linear:

y_r = A_r [x; 1]

3 · Defuzzify

Weighted average:

y = Σ f_r y_r / Σ f_r

One (γ, λ) pair, then shared stages 4 to 7 (squash, channel, install, benchmark)

Parameters

27 premise + 216 rule-output (27 × 2 × 4) = 243 with Triangular or TanhBell: the parameter-matched control

Gaussian: 18 + 216 = 234

Start and training

Rule outputs start anchored at the physics target at each rule's centre (#59, PR #68).

Training planned (#60): hybrid ANFIS, least squares for rule outputs, gradient steps for MF parameters.
