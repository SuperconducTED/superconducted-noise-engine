## Implementation approach

### The measurement

PR #162's head `d709fbb0` already contained `main` at `4f26881c`. So the trial merge
(`git merge-tree --write-tree origin/main d709fbb0`) returned the head's own tree, `263f6f22`, and the worktree
at `C:/t148`, clean at `d709fbb0`, held exactly the tree the merge would record.

Two commands were run there from the exact-pin interpreter (Python 3.12.10, NumPy 2.4.4, Qiskit 2.4.1,
Aer 0.17.2, pytest 9.0.3, `PYTHONPATH=src`):

```bash
python -m pytest -q -p no:cacheprovider
python -m pytest tests/ --collect-only -q -o addopts="" -p no:cacheprovider
```

| Step | When (UTC, 2026-11-23) | Result |
| --- | --- | --- |
| Passing run on tree `263f6f22` | 11:40 to 11:48 | 1439 passed in 466.85 s, none skipped, none failed |
| PR #162 merged | 11:51:24 | merge commit `1869d858`, parents `4f26881c` and `d709fbb0` |
| `git rev-parse 1869d858^{tree}` | after the merge | `263f6f229f6d97dcbdb68de61bd4d09d7999c590`, the same object |
| Collection on tree `263f6f22` | after the merge | 1439 tests collected |

So the run measured exactly the tree the merge commit records, although the commit did not yet exist when the
run started.

**One difference from the row's commands.** The passing run was started without the `tests/` argument. The
row's command is `python -m pytest tests/ -q -p no:cacheprovider`. `pyproject.toml` sets
`testpaths = ["tests"]`, so the two select the same tests, and the collection command, run with `tests/`,
gives the same 1439. The row says this.

### The import path

The exact-pin interpreter has the package installed in editable mode, pointing at another local worktree. Both
commands were therefore preceded by a print of `superconducted.__file__` in the same interpreter with the same
`PYTHONPATH=src`: it printed `C:\t148\src\superconducted\__init__.py`.

## Design decisions

- **Measure on the head's tree before merging, then confirm identity.** The alternative is to measure after
  the merge in a fresh worktree of `1869d858`. The head already contained `main`, so both give the same tree;
  measuring first also served as the pre-merge check. The precedent is PR #160's record for PR #155.
- **Keep the `1432` clause.** Dated rows are append-only: the earlier value stays as the measurement of
  `b9fcddea`, and the new clause is added after it.
- **List the open PRs that touch `tests/`.** Measured from each PR's changed files on 2026-11-23: #142, #143,
  #150, #156, #158 and #163. The earlier clause's list omitted #156; this one is measured, not copied.
