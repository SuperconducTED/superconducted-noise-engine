# 2026-08-19: ADR-012 closure

## Problem / Motivation

ADR-012 already described the shipped squashing behavior, but stayed as Open.
This change makes its decision without changing runtime behavior: the
noise-probability default must be explicit before the differentiable alternative 
is used in the SGD trainer work for ADR-014.
## What changed

| File | One-sentence description |

| `docs/decisions.md` |  Accept ADR-012, make pipeline-level default normative, and record code evidence.|
| `docs/state-of-the-project/2026-05-25-bootstrap-to-cycle-1.md` | Sync historical status table with accepted ledger entry.|

## Implementation approach

This is a documentation-only change to the ledger. Only for noise-probability pipelines, when a pipeline is constructed, `ProbabilityClip` is the default. `IdentitySquashing` and `SigmoidSquashing` are still available to choose, with the latter still remaining the differentiable path for ADR-014.

## Mathematical / Statistical details

N/A — only documnetation is changed.

## Design decisions

The ADR deliberately does not define a default selector at the module level. `FuzzyNoiseModel` and `FuzzyNoiseModelEnsemble` require a `SquashingStrategy`, which retains selection at the pipeline construction and avoids a change in behavior for other callers.
