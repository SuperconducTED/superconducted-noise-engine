# 2026-08-19: ADR-012 closure

## Problem / Motivation

ADR-012 already described the shipped squashing behavior, but remained Open.
This change ratifies its decision without changing runtime behavior: the
noise-probability default must be explicit before ADR-014's SGD trainer work
uses the differentiable alternative.

## What changed

| File | One-sentence description |
| --- | --- |
| `docs/decisions.md` | Marks ADR-012 Accepted, makes the pipeline-level default normative, and records code evidence. |
| `docs/state-of-the-project/2026-05-25-bootstrap-to-cycle-1.md` | Aligns the historical status table with the accepted ledger entry. |

## Implementation approach

This is a documentation-only ledger change. `ProbabilityClip` remains the
default only for noise-probability pipelines, selected when a pipeline is
constructed. `IdentitySquashing` and `SigmoidSquashing` remain selectable;
the latter remains the differentiable path for ADR-014.

## Mathematical / Statistical details

N/A — documentation-only change.

## Design decisions

The ADR deliberately does not introduce a module-level default selector.
`FuzzyNoiseModel` and `FuzzyNoiseModelEnsemble` require a
`SquashingStrategy`, keeping selection at pipeline construction and avoiding a
behavioral change for other callers.
